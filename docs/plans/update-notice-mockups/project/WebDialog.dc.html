How to update

Your downloads and settings stay in the data volume. Running downloads stop and resume after the restart.
Compose docker compose pull inbound && docker compose up -d inbound
docker run docker pull ghcr.io/kaan88/inbound:latest
Then start the container again with the same options. An image pinned to :0.7 gets 0.7.x updates; a new 0.8 needs the tag changed. Docker guide
