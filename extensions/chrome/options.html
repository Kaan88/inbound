Inbound Download Manager Bridge

Hands browser downloads to Inbound Download Manager. The desktop app keeps the download list.

Integration

New downloads use the app's default folder. Choose a one-off folder on the handoff screen.

File and site rules

Connection

The browser launches the native host named com.kaank.downloadmanager. The host is registered per user by the installer and must be present before automatic interception is useful. Unsupported requests stay in the browser.
