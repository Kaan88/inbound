Inbound Download Manager Bridge

Hands browser downloads to Inbound Download Manager. The desktop app keeps the download list.

Integration

When this is on, downloads that match your rules stop in Chrome and start again in the desktop app, and they leave Chrome's download list. For each one, the extension gives the app the file's address, the address of the page it came from, your browser's user agent, and your cookies for that site, so the app can download files that need your own login. The app keeps these on this computer with the download, the cookies encrypted, until you remove it, and sends the cookies only to that site. The address can also stay in the app's list of recent addresses. Nothing is sent to the developer. Privacy policy

Off unless you turn it on. It looks for video and audio addresses on each page you visit, keeps them in memory until the page is closed or reloaded, and sends one to the desktop app only when you choose to download it. To list a stream's qualities, opening the toolbar popup may request its playlist from the site hosting it, with your cookies only if that is the site you are on. YouTube is not supported, and the app refuses live streams and streams it detects as DRM-protected. Download only what you have the right to.

New downloads use the app's default folder. To use a different folder for one download, right-click its link and choose Download with Inbound Download Manager.

File and site rules

To keep a single download in Chrome, hold Delete while you click its link. To keep them all for a while, or for buttons and links inside embedded frames where holding Delete does not work, use Pause catching in the toolbar popup. The extension's script on each page checks only whether Delete is held; it does not record what you type.

Connection

This extension needs the Inbound Download Manager desktop app for Windows, and sends download details only to that app on this computer. Using the extension starts the app's background process if it is not running. If the app is not installed or cannot be reached, or it refuses a download, the download stays in Chrome. Once the app has accepted one, Chrome's copy is gone, so pause catching first for a file from a submitted form or a link that works only once.
