Inbound Download Manager Bridge

Hands browser downloads to Inbound Download Manager. The desktop app keeps the download list.

Integration

Automatic sending: checking…

When this is on, downloads that match your rules stop in your browser and start again in the desktop app, and they leave the browser's download list. For each one, the extension gives the app the file's address, the address of the page it came from, your browser's user agent, and your cookies for that site, so the app can download files that need your own login. The app keeps these on this computer with the download, the cookies encrypted, until you remove it, and sends the cookies only to that site. The address can also stay in the app's list of recent addresses. If you pair your own Inbound server below and send downloads there, the same details go to that server instead. Nothing is sent to the developer. Privacy policy

"Ask each time" opens a small window for each caught download, starting at the app's default folder, with Choose… for another folder and Keep in browser to leave it to the browser. The folder you choose there is for that download only. With a server paired below, the window also asks whether to save on this PC or on the server. The right-click menu always asks.

File and site rules

To keep a single download in your browser, hold Delete while you click its link. To keep them all for a while, or for buttons and links inside embedded frames where holding Delete does not work, use Pause catching in the toolbar popup. The extension's script on each page checks only whether Delete is held; it does not record what you type.

Access to sites

This browser has not given the extension access to the sites you download from, so it cannot read a site's cookies for the app or notice Delete held on a page. Downloads that need your login may fail in the app until you allow it.

Inbound server

Send downloads to your own Inbound server (the Docker or Linux version) as well as, or instead of, this PC. To get a code, open the server's web UI, then Settings, Paired browsers, and choose Pair a browser. The code works once, for ten minutes.

This address uses http://, so the pairing token and the cookies sent with each download cross your network unencrypted. That is fine on a home network you trust; put the server behind https:// otherwise.

Saved with Save settings. The server can be chosen once one is paired. If the place chosen can't take a download, it stays in your browser; it is never sent to the other place instead.

Connection

This extension needs the Inbound Download Manager desktop app for Windows, or an Inbound server paired above, and sends download details only to that app on this computer or to your server. Using the extension starts the app's background process if it is not running. If the app is not installed or cannot be reached, or it refuses a download, the download stays in your browser. Once the app has accepted one, the browser's copy is gone, so pause catching first for a file from a submitted form or a link that works only once.
