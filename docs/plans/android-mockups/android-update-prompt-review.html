How it behaves

Examples only. The three sample release notes and version are not a claim about a real release. Use the notes controls to inspect scrolling and the older-feed fallback.

The check and download states reflect the existing updater. Install continues to Android’s system installer; Later closes the prompt.

Implementation boundary

The current verified update manifest contains a version, size, URL and APK hash, but no release notes. Supplying authentic notes requires a compatible feed and trust design; old feeds should show the unavailable message. Notes should be rendered as bounded plain text, not interactive markup. This is a design proposal, not a released implementation.
