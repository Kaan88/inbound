## Final prompt

Use case: logo-brand. Create one original production Windows application icon for Rill, a personal download manager. A bold, simple, recognizable emblem suggesting two small flowing streams converging into a clear downward download arrow. Flat geometric silhouette with restrained depth and a polished rounded-square deep navy tile, cyan-to-teal stream mark, high contrast and generous clean edge spacing. Centered icon only, square composition, genuinely transparent background outside the rounded tile. Must remain legible at 16 and 32 pixels. No letters, no words, no mockup, no surrounding objects, no watermark, no copied brand imagery, no thin decorative strokes, no cloud or globe.

Existing application IDs, native-host name, extension key, update feed identity, install/data directories and shortcut filenames are retained for upgrade compatibility. Display branding is Rill Download Manager.
