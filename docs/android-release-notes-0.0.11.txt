Torrents can be downloaded on the phone, from a magnet link or a .torrent file, with a choice of files. They run only on Wi-Fi by default, and seeding runs only on Wi-Fi while charging.
TorBox can be used from the phone: add a magnet or link, see cached results at once, and follow items in My TorBox and in Downloads.
Finished archives can be extracted on the phone, with a password sheet, saved passwords and a choice to delete the archive afterwards.
Import a list adds many links at once from a saved list file.
Remote Files lists Google Drive, OneDrive and Dropbox folders faster, and a cloud location can use its own client ID.
Fewer wake-ups while the phone is idle, and keys and passwords are only sent to this phone or to a Host reached over HTTPS.
