Torrents

Download torrents on this PC
What turning this on does Magnet links and .torrent files can then download straight from other people's computers (peers), not only through TorBox.
  • Peers see this PC's public IP address, and it sees theirs.
  • While a torrent downloads, and afterwards until it reaches the seeding goal below, the app uploads pieces to other peers.
  • The app listens on one network port, and a small background program runs only while a torrent is active or seeding. When this is off, nothing runs and no port is open.
  • Download only what you have the right to download.

When TorBox is also set up, the Add dialog asks which one to use. TorBox stays the default.
