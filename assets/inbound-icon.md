# Inbound app icon

Original icon drawn in code by `scripts\draw-inbound-icon.ps1`: a white plane descending onto a blue runway, on a rounded navy-to-blue tile (#0B2545 to #1F6FC5, matching the progress blue). No external art or brand imagery.

Regenerate: `scripts\draw-inbound-icon.ps1` then `scripts\build-icons.ps1` (writes `assets\app.ico`, `assets\app.png` and extension icons).

Existing application IDs, native-host name, extension key, update feed identity, install/data directories and shortcut filenames are retained for upgrade compatibility. Display branding is Inbound Download Manager.
