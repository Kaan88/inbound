Update NAS (Docker)

0.7.2 → 0.7.4 · released 20 Nov 2026
Inbound can't update a Docker server from here. On the machine that runs it, pull the new image and start the container again. Its downloads and settings stay in its data volume, and this window reconnects by itself.
Compose docker compose pull inbound && docker compose up -d inbound
docker run docker pull ghcr.io/kaan88/inbound:latest
