Automatic sending

When a download is sent

The default folder is the one set below for this PC, or the server's when downloads go to the server. "Ask where to save" asks in the extension's toolbar popup, under its icon; a small window asks instead when the popup can't open (Chrome or Edge before 127, Firefox before 149, or the browser not in front). The folder chosen there is for that download only. The right-click menu's download goes straight to the default folder, or asks in a window with "Ask where to save".

While a download from the browser runs

Off: the browser keeps the focus, and the extension's icon shows the progress: a green ring while downloading, orange when paused, red when one failed. On: the app opens its progress window and its finished window, as for downloads added in the app.

Chrome or Edge before 127, and Firefox before 149, can't open the popup by themselves (nor when the browser isn't in front); the icon flashes there instead.

Default folder for browser downloads on This PC

Downloads from the browser go here when they go to This PC, and the download windows call it the default folder. Downloads added in the app keep the app's default folder. The server keeps its own.

Ask where to save starts on

Where the download windows and the popup start; you can still pick any folder there. Last used remembers one folder for this PC and one for the server. Custom is a folder on this PC; the server starts on its default folder. A folder that no longer exists starts on the default folder.

Which button the download windows make the main one. A choice there is for that download only.

Catching

File types

Sites

To keep a single download in your browser, hold Delete while you click its link. To keep them all for a while, or for buttons and links inside embedded frames where holding Delete does not work, use Pause catching in the toolbar popup. The extension's script on each page checks only whether Delete is held; it does not record what you type.

Server

Send downloads to your own Inbound server (the Docker or Linux version) as well as, or instead of, this PC. To get a code, open the server's web UI, then Settings, Sign-in and browsers, and choose Pair a browser. The code works once, for ten minutes.

Shown in Send to and in the popup. Leave it empty to use the name the server gives when it is paired, or its address.

This address uses http://, so the pairing token and the cookies sent with each download cross your network unencrypted. That is fine on a home network you trust; put the server behind https:// otherwise.

Where automatic downloads go

The server can be chosen once one is paired. If the place chosen can't take a download, it stays in your browser; it is never sent to the other place instead.

Site access

This browser has not given the extension access to the sites you download from, so it cannot read a site's cookies for the app or notice Delete held on a page. Downloads that need your login may fail in the app until you allow it.

Connection

This extension needs the Inbound Download Manager desktop app for Windows, or an Inbound server paired on the Server page, and sends download details only to that app on this computer or to your server. Using the extension starts the app's background process if it is not running. If the app is not installed or cannot be reached, or it refuses a download, the download stays in your browser. Once the app has accepted one, the browser's copy is gone, so pause catching first for a file from a submitted form or a link that works only once.

About

Inbound Download Manager Bridge

Hands browser downloads to Inbound Download Manager. The desktop app keeps the download list.

What is sent

When automatic sending is on, downloads that match your rules stop in your browser and start again in the desktop app, and they leave the browser's download list. For each one, the extension gives the app the file's address, the address of the page it came from, your browser's user agent, and your cookies for that site, so the app can download files that need your own login. The app keeps these on this computer with the download, the cookies encrypted, until you remove it, and sends the cookies only to that site. The address can also stay in the app's list of recent addresses. If you pair your own Inbound server and send downloads there, the same details go to that server instead. Nothing is sent to the developer.
